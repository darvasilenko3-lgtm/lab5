1. GET запит :
curl -i http://127.0.0.1:3000/200 -o 200.jpg

2. Повторний GET запит :
curl -i http://127.0.0.1:3000/200 -o 200_cached.jpg

3. PUT запит :
curl -i -X PUT --data-binary @"200.jpg" http://127.0.0.1:3000/201

4. DELETE запит :
curl -i -X DELETE http://127.0.0.1:3000/201

5. Запит з недозволеним методом :
curl -i -X POST http://127.0.0.1:3000/200
